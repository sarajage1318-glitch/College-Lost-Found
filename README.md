# College Lost & Found Portal

A web-based **College Lost & Found Portal** developed to help students report, search, match, claim, and return lost and found items within a college campus.

## 📌 Project Overview

The College Lost & Found Portal provides a centralized platform where students can report items they have lost or found. The system helps connect matching lost and found reports and allows students to submit claim requests.

An administrator can review reports and student claim requests, approve or reject requests, and mark items as returned.

## ✨ Features

* Student Registration and Login
* Report Lost Items
* Report Found Items
* Browse Lost and Found Items
* Automatic Lost–Found Matching
* View Item Details
* Claim / Connect with Finder
* Student Claim Requests
* Admin Approval and Rejection
* Mark Item as Returned
* Item Status Tracking
* Reporter Information

## 🔄 Project Workflow

1. Student registers and logs into the portal.
2. Student reports a lost item.
3. Another student reports the corresponding found item.
4. The system identifies and links the matching items.
5. The student submits a claim request.
6. Admin reviews the claim request.
7. Admin approves or rejects the request.
8. After successful handover, the item is marked as **Returned**.

## 🗄️ Database

The project uses a MySQL database named:

`college_lost_found`

The database stores information related to:

* Students / Users
* Lost and Found Items
* Claim Requests
* Item Matching
* Item Status

## ▶️ How to Run

1. Install Python.
2. Install the required Python packages.
3. Start **MySQL** using XAMPP.
4. Create/import the `college_lost_found` database in phpMyAdmin.
5. Open the project folder in a terminal.
6. Run:

```bash
python app.py
```

7. Open the application in a browser:

```text
http://127.0.0.1:5000
```
